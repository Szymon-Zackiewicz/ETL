# ETL & Data Warehousing Project (SAS DI Studio)

### Overview
This project focuses on designing and implementing ETL processes and data warehouse structures using SAS Data Integration Studio and the AdventureWorks database.

### Key elements:

* Designed and implemented multiple ETL workflows
* Built a star schema (fact & dimension tables) for analytical reporting
* Performed data integration from multiple sources
* Applied data cleaning, validation, and quality improvement techniques
* Worked with business domains such as sales, logistics, and production

### Project scope:

* Sales analysis (star schema)
* Delivery delay analysis
* Purchase cost analysis
* Product quality analysis
* Data quality improvement pipeline

### Tools:

* SAS Data Integration Studio
* SQL-based data sources (AdventureWorks)
